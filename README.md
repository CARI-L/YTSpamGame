# YTSpamGame
Using machine learning and some more python magic, YOU TOO can type in your very own YouTube spam comments, testing the algorithm!

## Features

- Input and validate spam comments
- View results of 5 different validation models

## Compilation

### Dependencies

Install UCI Machine Learning Repo:
```
pip install ucimlrepo
```

Install sci-kit-learn:
```
pip install sklearn
```

Install pandas:
```
pip install pandas
```

### Running 
```
python spam_game.py
```
